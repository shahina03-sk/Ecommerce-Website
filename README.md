# Ecommerce Website

Modern responsive e-commerce frontend based on the supplied Full Stack Java guide.

## Run
Open `index.html` in a browser.

## Features
- Product catalogue
- Search, category and price sorting
- Product details modal
- Cart count persisted with localStorage
- Responsive landing page

## Java/Spring/MySQL extension
Connect the UI to `/products`, `/products/:id`, `/cart`, and `/checkout` endpoints from a Spring MVC backend. The current product data is intentionally mocked for an immediately runnable demo.
